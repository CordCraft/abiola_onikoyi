# Jarvis for iPhone

Native companion to the Jarvis second brain at abiolaonikoyi.com/jarvis. Expo SDK 58, iOS only, distributed through TestFlight (internal testing, no App Store review).

## What it does

- **Today**: what is left today in order (overdue, today, in progress, up next). Tap the circle to finish (with Undo), tap a task for Start / Do it today / Tomorrow / priority, add a task at the bottom, "Read it to me" speaks the summary.
- **Talk**: hands-free voice with the website's Whisper (listen) and Kokoro (speak) service and the same chat brain and tools. Desk mode waits for "Hey Jarvis" and keeps listening with the screen off.
- **Chat**: text chat with the same brain.
- **Siri** (no Shortcuts setup needed): "What's left in Jarvis", "Talk to Jarvis", "Mark a task done in Jarvis", "Add a task in Jarvis", "Move a task to tomorrow in Jarvis", "Start a task in Jarvis", "Ask Jarvis a question", "Start desk mode in Jarvis".
- **Widgets**: home screen small, medium and large (tap-to-complete circles), lock screen circular, rectangular and inline, and a "Talk to Jarvis" control for Control Center, the lock screen and the Action Button.
- **Notifications**: through the site's companion push (`app-push.ts`). Every banner has a Reply box that goes straight to Jarvis; tasks also have Done, signals Do it (Face ID) / Not now. Tapping opens the web reply page.
- **Songs**: a "Like this song" control (Control Center, Action Button, lock screen) and Siri phrase save what YouTube Music is playing; the Songs screen shows the Suno pack Jarvis wrote, with Copy buttons and Open Suno, plus ACE-Step takes. Guide: `docs/JARVIS-SONGS.md` in the repo root.
- **Face ID** lock on launch and after 3 minutes away (voice mode opened by Siri skips it).

"Hey Jarvis" without "Hey Siri": iPhone Settings, Accessibility, Vocal Shortcuts, Set Up, pick the Jarvis shortcut "Talk to Jarvis", say "Hey Jarvis" three times.

## How it connects

- Pairing: Jarvis web Settings, "iPhone app", "Pair this iPhone" mints a device token (JWT, audience `jarvis-mobile`, 400 days) and opens `jarvisapp://pair?token=...&host=...`. Unpair there revokes it at once (devices live in JarvisSetting `mobile_devices`, checked by `getSession()` on every Bearer request).
- The app sends `Authorization: Bearer <token>` to the existing `/jarvis/api/*` routes (chat, voice, task-action, signal-action) plus `/jarvis/api/mobile/{today,tasks}`, and to `/api/jarvis-app/{register,reply}` for push.
- The token sits in the Keychain (expo-secure-store) and is mirrored into the App Group `group.com.abiolaonikoyi.jarvis` so the widget and Siri extension can call the site.

## Layout

- `src/app/*` screens (Expo Router), `src/lib/*` API client, voice engine, notifications, storage.
- `targets/_shared/JarvisCore.swift` models, API client and all App Intents (linked into the app and both extensions).
- `targets/widget/` WidgetKit extension (widgets + control). `targets/intents/` App Intents extension with the Siri phrases (`AppShortcutsProvider`).
- `ios/` is generated by prebuild on EAS. Never commit or hand-edit it.

## Shipping

`.github/workflows/jarvis-ios.yml` (repo root):
- On a push that touches `mobile/`: JavaScript-only changes go out as an over-the-air update (`eas update`, branch `production`) and appear at the next app launch. Native changes (Swift, plugins, packages, app.json) trigger a new build that auto-submits to TestFlight. The split uses the fingerprint runtime version.
- 02:00 UTC on the 1st of every other month: a fresh TestFlight build, so the 90-day TestFlight expiry never bites.
- Actions tab, "Jarvis iOS", Run workflow: force a build.

### One-time setup (owner)

1. Apple signing (needs your Apple ID and 2FA, so it is interactive):
   ```
   cd mobile
   npx eas-cli@latest build -p ios --profile production --auto-submit
   ```
   Let EAS log in to Apple, create the distribution certificate and the three provisioning profiles (app, widget, intents), register the App Group, create the App Store Connect app, and generate an App Store Connect API key for submissions. After this, builds and submissions run unattended.
2. GitHub secret: expo.dev, Account settings, Access tokens, create a token, then GitHub repo Settings, Secrets and variables, Actions, add `EXPO_TOKEN`.
3. TestFlight on the iPhone: install the build, open Jarvis, pair from web Settings.

## Developing

```
npm install --legacy-peer-deps
npx tsc --noEmit
npx expo export --platform ios   # bundle check without a Mac
```
Native code can only be compiled on EAS (no Mac here). After changing anything in `targets/`, push and watch the build log on expo.dev.
